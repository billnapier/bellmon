# Implementation Plan: Phase 0.1 Infrastructure & Guardian CI/CD Foundation

**Branch**: `001-phase-0-1-infrastructure-poc` | **Date**: 2026-08-21 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `specs/001-phase-0-1-infrastructure-poc/spec.md`

## Summary

Establish foundational GCP declarative infrastructure using Terraform and set up GitHub Actions CI/CD using Google's Guardian (`abcxyz/guardian`) workflow. This provisions GCP Secret Manager secret containers (`canvas-api-token`, `powerschool-credentials`), Google Cloud Firestore in Native Mode, IAM service account bindings, and a skeleton GCP Cloud Run Job resource definition, ensuring all subsequent ingestion modules deploy into a zero-trust production environment.

## Technical Context

**Language/Version**: Python 3.11+, HashiCorp Terraform 1.5+  
**Primary Dependencies**: `google-cloud-firestore`, `google-cloud-secretmanager`, `pytest`, `abcxyz/guardian` GitHub Actions  
**Storage**: Google Cloud Firestore (Native Mode) for state/sessions, GCP Cloud Storage for Terraform remote backend  
**Testing**: `pytest`, `terraform validate`, `tflint`  
**Target Platform**: GCP (Cloud Run Jobs, Firestore, Secret Manager, IAM)  
**Project Type**: Single project with infrastructure (`terraform/`) and Python source (`src/`)  
**Performance Goals**: CI/CD speculative `guardian plan` completes in under 3 minutes; zero-latency secret resolution  
**Constraints**: Single production environment ("Test in Prod"), zero hardcoded plain-text credentials, 100% serverless  
**Scale/Scope**: Serverless batch job executing sub-daily for student academic monitoring  

## Constitution Check

- [x] **Test-in-Prod Single Environment**: Standardized directly on GCP production environment; no staging complexity.
- [x] **Zero-Trust Secrets Management**: All tokens and SAML credentials stored strictly in GCP Secret Manager.
- [x] **Declarative Infrastructure**: 100% of GCP resources managed via Terraform in `terraform/`.
- [x] **Automated CI/CD**: Guardian GitHub Actions (`abcxyz/guardian`) executes speculative plans on PRs and automated applies on `main`.
